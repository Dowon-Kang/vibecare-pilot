# `pilot-0.9.0` 골격근량 등급별 고정 매핑

최신 유효 API 골격근량을 `SMM kg / 키 m²`로 정규화하고 성별 연구 경계로 낮음·중간·높음으로 분류한다. 선택 부위에는 아래 고정값을 추가 보정 없이 적용한다. 실제 장치 실행은 금지하며 Mock 시뮬레이터에서만 사용한다.

| 등급 | 전신 | 어깨 | 팔 | 배 | 종아리·허벅지 |
|---|---|---|---|---|---|
| 낮음 | 25분·8Hz·80% | 20분·15Hz·75% | 15분·20Hz·70% | 10분·25Hz·65% | 5분·35Hz·60% |
| 중간 | 30분·8Hz·90% | 25분·15Hz·85% | 20분·20Hz·80% | 15분·25Hz·75% | 10분·35Hz·70% |
| 높음 | 35분·8Hz·99% | 30분·15Hz·90% | 25분·20Hz·85% | 20분·25Hz·80% | 15분·35Hz·75% |

현재 연구 경계는 여성 `≤5.75 / 5.75 초과~6.75 이하 / >6.75kg/m²`, 남성 `≤8.50 / 8.50 초과~10.75 이하 / >10.75kg/m²`다. 등급 판정은 `SMM / 키²`의 반올림 전 원값으로 비교하고, API 응답과 화면에 보여 주는 근육지수만 소수 둘째 자리로 반올림한다. 예를 들어 남성 170cm·SMM 24.57kg은 원값이 약 8.5017이므로 표시값은 8.50이어도 `중간`이다. 이는 근감소증 진단이 아닌 Janssen 2004 연구 층화이며, FITRUS SMM 정의의 동등성은 별도 검증이 필요하다. DB에는 API 원본 이력을 저장하고 화면에서는 최신 골격근량과 직전 기록을 비교한다.
