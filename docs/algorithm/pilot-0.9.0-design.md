# `pilot-0.9.0` 골격근량 등급별 고정 매핑

이 문서는 이전 버전의 기록이다. 현재 연구용 Mock 계수는 [`pilot-0.9.1`](pilot-0.9.1-design.md)을 따른다.

## 설정된 보정계수 적용 (2026-10-04)

사용자 요청에 따라 시뮬레이션 후보 출력에는 규칙의 성별·연령·체지방 계수를 적용한다. 체지방 계수는 유효 측정 4건의 평균 체지방률로 선택한다. 근육량은 이미 최신 SMM/키 지수로 낮음·중간·높음 부위별 설정을 선택하므로 별도 출력 계수는 중립값 1을 유지한다. 계산은 `부위·근육등급 기본 출력 × 성별 계수 × 연령 계수 × 체지방 계수 × 근육 계수`이며, 원시 계산값을 규칙의 최소·최대 출력과 해당 기본 출력으로 제한한 뒤 정수로 반올림한다. 시간과 Hz는 보정하지 않는다. 계산 결과에는 각 계수, 전체 곱, 반올림 전 출력값을 남긴다.

현재 저장된 `pilot-0.9.0` 규칙의 모든 계수는 1.0이므로 기존 추천 수치는 바뀌지 않는다. 1.0 미만의 계수는 승인된 규칙에서만 주입한다. 이 계수는 임상적으로 검증된 처방값이 아니며 실제 장치 실행은 계속 금지한다.

최신 유효 API 골격근량을 `SMM kg / 키 m²`로 정규화하고 성별 연구 경계로 낮음·중간·높음으로 분류한다. 선택 부위의 아래 고정값을 기본값으로 사용하고, 승인된 규칙에 비중립 계수가 있으면 출력에만 곱한다. 실제 장치 실행은 금지하며 Mock 시뮬레이터에서만 사용한다.

| 등급 | 전신 | 어깨 | 팔 | 배 | 종아리·허벅지 |
|---|---|---|---|---|---|
| 낮음 | 25분·8Hz·80% | 20분·15Hz·75% | 15분·20Hz·70% | 10분·25Hz·65% | 5분·35Hz·60% |
| 중간 | 30분·8Hz·90% | 25분·15Hz·85% | 20분·20Hz·80% | 15분·25Hz·75% | 10분·35Hz·70% |
| 높음 | 35분·8Hz·99% | 30분·15Hz·90% | 25분·20Hz·85% | 20분·25Hz·80% | 15분·35Hz·75% |

현재 연구 경계는 여성 `≤5.75 / 5.75 초과~6.75 이하 / >6.75kg/m²`, 남성 `≤8.50 / 8.50 초과~10.75 이하 / >10.75kg/m²`다. 등급 판정은 `SMM / 키²`의 반올림 전 원값으로 비교하고, API 응답과 화면에 보여 주는 근육지수만 소수 둘째 자리로 반올림한다. 예를 들어 남성 170cm·SMM 24.57kg은 원값이 약 8.5017이므로 표시값은 8.50이어도 `중간`이다. 이는 근감소증 진단이 아닌 Janssen 2004 연구 층화이며, FITRUS SMM 정의의 동등성은 별도 검증이 필요하다. DB에는 API 원본 이력을 저장하고 화면에서는 최신 골격근량과 직전 기록을 비교한다.
