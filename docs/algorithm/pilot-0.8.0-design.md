# `pilot-0.8.0` 부위별 시뮬레이션 설계

## 목적과 안전 경계

이 버전은 신체 부위를 선택했을 때 프로젝트가 정한 기준 시간·주파수·기기 출력과 보정 과정을 재현 가능하게 보여 주는 **연구용 가설 시뮬레이터**다. 임상 처방이나 의료기기 제어 알고리즘이 아니다. 모든 결과는 `physicalExecution=PROHIBITED`, `realDeviceSendAllowed=false`이며 Mock 장치에만 전달한다.

## 입력

- 참여자: 나이, 성별, 키
- 같은 참여자·같은 기기·같은 획득 프로토콜에서 얻은 최신 유효 SMM 체성분 4건
- 선택 부위: 전신, 어깨, 팔, 복부, 허벅지, 종아리
- 안전 문진: 통증, 어지럼, 전문가 보류 지시

4건의 체중·BMI·체지방률·체지방량·골격근량을 산술평균한다. SMM 정의, 단위, 측정 방법, 획득 프로토콜, 시각 또는 품질이 유효하지 않으면 계산을 `REVIEW`로 닫는다. 안전 문진 중 하나라도 참이면 `BLOCKED`다.

## 기준값

| 부위 | 시간 | 주파수 | 기준 기기 출력 |
|---|---:|---:|---:|
| 전신 | 30분 | 8Hz | 90% |
| 어깨 | 25분 | 15Hz | 85% |
| 팔 | 20분 | 20Hz | 80% |
| 복부 | 15분 | 25Hz | 75% |
| 허벅지 | 10분 | 35Hz | 70% |
| 종아리 | 10분 | 35Hz | 70% |

이 표와 보정계수는 사용자가 제공한 프로젝트 가설이며 임상적으로 검증된 안전 한계가 아니다.

## 보정 수식

```text
C = C성별 × C나이 × C체지방 × C근육량
계산 출력 = 부위 기준 출력 × C
최종 출력 = round(clamp(계산 출력, 설정 최솟값, min(설정 최댓값, 부위 기준 출력)))
```

- 성별: 여성 `0.95`, 남성 `1.00`
- 나이: 60세 미만 `1.00`, 60대 `0.95`, 70대 `0.90`, 80세 이상 `0.85`
- 체지방률(연구용 임시 구간): 여성 `<20` 또는 `>35`, 남성 `<10` 또는 `>28`이면 `0.95`, 그 외 `1.00`
- 근육량: 현재 `1.00` 중립값이다. SMM은 데이터 적격성과 화면 근거에는 사용하지만, 근육량과 기기 출력의 인과 매핑 근거가 확보되기 전에는 출력 보정에 사용하지 않는다.
- 출력 제한 기본값: `20%..99%`, 그리고 해당 부위 기준 출력보다 높이지 않는다.

시간과 주파수는 선택 부위의 기준값을 유지하고 출력만 보정한다. 계수, 임계값, 제한값은 서버 버전 규칙에 저장하며 앱 화면에 각각의 값과 이유를 표시한다.

## 예제

전신 기준 90%에서 75세 여성이고 평균 체지방률이 18%이면:

```text
90 × 0.95 × 0.90 × 0.95 × 1.00 = 73.1025 → 73%
```

30세 남성이고 정상 구간이면 `90 × 1 × 1 × 1 × 1 = 90%`다.
