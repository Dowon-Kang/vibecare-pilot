# 수치 표시와 설문 반영 — 2026-09-13

## 기기 출력의 의미 — 사용자 확인 반영

화면의 %는 진동 기기 자체의 출력 설정값이다. 화면 명칭을 ‘기기 출력’으로 통일한다. 기존 API 필드 `intensityPct`도 이 설정값을 뜻한다. 50% 설정이 실제 가속도·진폭·전력의 절반이라는 의미는 아니며, 물리량과의 관계는 기기 보정 자료로 확인한다. 종료 설문은 해당 출력을 사용자가 얼마나 강하게 느꼈는지 묻고 다음 출력 설정의 상한에 반영한다. 아래 과거 기록의 ‘강도’는 이 출력 설정 또는 설문 체감을 가리킨다.

현재 `mobile-app`·`backend-api` 구조와 `pilot-0.8.0` 구현을 기준으로 확인했다. 이전 `flutter_app`·`worker` 구조는 복원하지 않았다.

## 이번에 개선한 화면

- 추천 강도 숫자: 32 → 64, 시간·주파수: 20 → 34. 강도와 시간·주파수를 두 줄로 나누어 표시한다.
- 체중·체지방·골격근량·BMI: 작은 4열에서 2열 카드로 변경하고 숫자는 19 → 28로 키웠다. 큰 글자 설정에서는 1열이다.
- 숫자를 칸에 맞춰 강제로 축소하던 측정값 FittedBox를 제거했다.
- 측정 기반 자동값 / 지난 설문 반영 자동값 / 직접 조절 중을 구분한다.
- 설문의 선택 RPE를 32 크기로 표시하고 ‘0점 · 힘들지 않음’ 버튼을 추가했다. 미선택을 자동으로 0점 처리하지 않는다.

수치 가독성을 우선했다. 작은 화면에서 모든 항목을 한 화면에 압축하지 않고 아래 내용을 스크롤로 읽는다. 실행 버튼은 고정한다.

## 자동 조절과 설문은 어떻게 연결되나

현재 프로젝트에는 종료 후 강도·시간·주파수 체감, 힘듦(RPE), 통증, 어지럼을 수집하고 다음 추천에 반영하는 기능이 이미 구현되어 있다. 이번 작업에서는 이를 중복 구현하지 않고 흐름과 저장·서버 검증을 재검사했다.

1. 확인된 측정값과 현재 연구 규칙으로 기본 후보를 자동 계산한다.
2. 종료 후 설문을 저장한다.
3. 다음 후보는 측정 기반 결과와 설문 강도 상한 중 더 낮은 값을 사용한다.
4. 직접 조절도 자동 추천보다 높일 수 없다.

현재 시연 정책 `feedback-0.3.0`:

| 답변 | 다음 사용 |
|---|---|
| 강했어요 또는 RPE 7 이상 | 지난 강도의 90%로 상한 감소. 50% → 45% |
| 적당했어요·약했어요, 불편 보고 없음 | 지난 상한 유지. 자동 증가 없음 |
| 통증·어지럼 | 담당자 확인 전 사용 보류 |
| 불편 보고 없는 사용자 중지 | 중지 사실만 기록하고 다음 사용 허용 |
| 시간이 길었어요 또는 주파수 느낌이 강했어요 | 임의로 시간·Hz를 조절하지 않고 사용 보류 |

측정 원본 자체를 바꾸는 기능이 아니다. 설문에 따라 자동 조정되는 것은 다음 시뮬레이터 강도 상한이다. 실제 진동 장치 출력이나 임상적으로 검증된 처방 조절은 아니다.
